# Arte en Lomillo

Sitio web oficial de **Arte en Lomillo**, desarrollado por **Búho's Software**.

## Descripción

Arte en Lomillo es una tienda especializada en artesanías bordadas a mano, donde cada pieza refleja tradición, calidad y dedicación.

Este proyecto fue desarrollado como un sitio web estático optimizado para ofrecer una experiencia rápida, accesible y adaptable a dispositivos móviles.

## Características

- Diseño responsivo (Mobile First)
- Catálogo dinámico mediante JSON
- Contador de "Me gusta" compartido con Google Apps Script
- Integración directa con WhatsApp
- Optimización para SEO
- Código HTML, CSS y JavaScript puro (sin frameworks)

## Tecnologías

- HTML5
- CSS3
- JavaScript (ES6)
- Google Apps Script
- Google Sheets
- GitHub Pages
